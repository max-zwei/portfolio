# Skills

A _skill_ is a markdown file that teaches an LLM how to do one job
hopefully reliably and repeatible.

This folder contains the ones I've used for this project. Feel free to install them with your LLM of choice.

I'm still wondering what an effective and also efficient skill.md could look like. I for example have doubts that the English language is the best way to define it. I would rather expect to use some programming language in order to clearly define a skill. Let's see how this will develop over time!
